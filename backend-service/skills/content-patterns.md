# Content Patterns for SEO Blog

## AEO / GEO Blocks

Use Answer Engine Optimization (AEO) and Generative Engine Optimization (GEO) patterns so content is extractable for AI search and citation.

### Definition Block
- For "what is X" queries: start with a direct, concise definition in the first paragraph
- The definition must be self-contained (no "as mentioned above")
- 2-4 sentences max, then expand

### Step-by-Step Block
- For "how to X" queries: use numbered steps
- Each step is a complete instruction
- No vague references ("do the previous step")

### FAQ Block
- Place at the end of the article
- Each question = search query people actually ask
- Answer in 2-4 sentences, self-contained

## Structure Requirements

- H2/H3 headings must be formulated as search queries
- Each paragraph should be self-sufficient (extractable for AI citation)
- One clear idea per paragraph
- No orphan H3 (every H3 under an H2)

## Keyword Placement

- Title: include primary keyword
- First paragraph: keyword within first 100 words
- At least one H2: contain keyword or close variant
- Meta title: keyword near the beginning
